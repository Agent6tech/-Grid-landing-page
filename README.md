### What I Learned

While working on this project, I focused on creating a clean layout using CSS Grid and making the design responsive across different screen sizes.

I also practiced organizing CSS styles, maintaining consistent spacing, and ensuring that interactive elements provide clear hover and focus states.

One of the key concepts reinforced by this challenge was using CSS Grid to create a structured layout:

```css
.stats-grid {
  display: grid;
  grid-template-columns: repeat(2, 1fr);
  gap: 1px;
}
```

This creates a two-column grid with consistent spacing between items. The exact styling can be adjusted to match the design.
